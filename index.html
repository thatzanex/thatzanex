01 Now

01

In progress since 19.09.2026

Flagship title of Atlantic Studios. A German Bundeswehr roleplay game on Roblox.

Bundeswehr Roleplay, rebuilt from scratch.

Every script and every UI is being rewritten. The old game is kept only as a reference for how things behaved and as a source of assets — models, clothing, animations and sounds. The new version lives in a separate dev place and, once ready, is published over the main place so every player keeps their data.

  1. 27Days into the revamp
  2. 9System groups
  3. 0Legacy scripts reused

Release path

  1. OldGame/ Reference & asset source only
  2. Dev place New build, src/ as source of truth
  3. Haupt Spiel Published over, data preserved

Player data

  1. PlayerData_v2 Read-only
  2. PlayerData_v3 Migrated on each player's first join

Tech stack & decisions

Language
Luau for all code. src/ is the source of truth — Studio is only used to deploy and test.
Interface
React-Luau (react-lua, the newer form of Roact) for the HUD, vendored and loaded through a single entry module.
State & motion
Charm for UI state and Ripple for spring animations, wrapped in our own useAtom and useSpring hooks.
Deploy
No Rojo, no Wally. Deploys run through Studio MCP and a small local HTTP server.
Combat
Our own server-authoritative combat system. A-Chassis stays for vehicle physics.
Architecture
Systems sorted into nine groups — Core, Economy, Arsenal and more. Each exposes a ClientAPI or ServerAPI, and every file opens with a doc header.
Tooling
Python checks for folder layout and tests, plus luau-compile for syntax.
Game design
R6 rig. German first, with every string going through LocaleAPI. UI style picked through mockup rounds.

Most core systems are built — the rest is tracked on the checklist.

02 Journey

02

From a two-person idea to a running studio.

Two years, two games, one rebuild.

  1. 18.05.2024

    Founded Atlantic Studios

    Co-founded a small Roblox development studio with two others. What started as a side project became the foundation for everything I've shipped since.

  2. Flagship

    Bundeswehr Roleplay

    The project I've put the most hours into by far. Beyond in-game scripting, I built the ecosystem around it: the bwrp.net website and staff dashboard, Discord shift-logging automation, a dynamic weather system and a custom texture pack.

  3. 25.06.2026

    Started Jugendtreff Hangout

    A different tone from BWRP — a relaxed hangout experience, built from the ground up.

  4. 18.09.2026

    Jugendtreff shipped

    Completed and published. Because of low player counts, further development is on ice for now.

  5. 19.09.2026 · Now

    The BWRP revamp begins

    A full rewrite of the flagship title — new architecture, new UI, existing player data carried over.
